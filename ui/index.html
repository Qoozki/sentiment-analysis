Data cleaning is automatic before every analysis: text is normalized (spacing, HTML, links, hidden characters, stretched letters, Arabic marks; capitals, punctuation and emojis are kept), then empty reviews, empty columns and duplicate rows are removed. The results show what changed, and the original wording of changed rows is kept in a “…_original” column.
CSV, TSV, Excel or JSON, up to 5,000 rows. For bigger data or several files use Bulk.
Pick several files at once. Every file needs the same text column. Large jobs keep running on the server and are saved to History when they finish.
